## Configuracion declarativa

### Backend (Railway)

`tb2/backend/railway.json`:
```json
{
  "$schema": "https://railway.com/railway.schema.json",
  "build": {
    "builder": "DOCKERFILE",
    "dockerfilePath": "docker/Dockerfile"
  },
  "deploy": {
    "healthcheckPath": "/v3/api-docs",
    "healthcheckTimeout": 180,
    "restartPolicyType": "ON_FAILURE",
    "restartPolicyMaxRetries": 5
  }
}
```

Variables de entorno seteadas en el dashboard de Railway:

| Variable | Origen del valor |
|---|---|
| `SPRING_PROFILES_ACTIVE` | `prod` (literal) |
| `DB_HOST` | `${{Postgres.PGHOST}}` (referencia dinamica al servicio Postgres) |
| `DB_PORT` | `${{Postgres.PGPORT}}` |
| `DB_NAME` | `${{Postgres.PGDATABASE}}` |
| `DB_USER` | `${{Postgres.PGUSER}}` |
| `DB_PASSWORD` | `${{Postgres.PGPASSWORD}}` |
| `JWT_SECRET` | Generado aleatoriamente (60 chars) |
| `CORS_ALLOWED_ORIGINS` | `https://ya-quedo.vercel.app` |
| `PORT` | Inyectado automaticamente por Railway |

Dockerfile (`tb2/backend/docker/Dockerfile`) multi-stage:
1. **Builder stage**: `maven:3.9-eclipse-temurin-21`, build con `mvn clean package -DskipTests`
2. **Runtime stage**: `eclipse-temurin:21-jre-alpine`, copia el jar y arranca con `java -jar app.jar`

`src/environments/environment.ts` (production):

### Landing Page (GitHub Pages)

- Source: rama `main` carpeta `/` (root)
- Auto-deploy: push a `main` → propagacion ~2 min
- Custom domain: no configurado (usamos subdominio `*.github.io`)
- HTTPS: forzado por GitHub Pages

## Flujo de despliegue end-to-end

```
Developer push a develop
        │
        ├─> Vercel detecta el push
        │    └─> npm install → ng build → publish dist/yaquedo-web/browser
        │         └─> https://ya-quedo.vercel.app actualizado (~2 min)
        │
Developer crea PR develop → main
        │
        ├─> Merge a main
        │    ├─> Railway detecta el push
        │    │    └─> docker build → docker run → healthcheck /v3/api-docs
        │    │         └─> https://yaquedotetradev-production.up.railway.app actualizado (~5 min)
        │    │
        │    └─> GitHub Pages detecta el push
        │         └─> jekyll build (vanilla) → https://yagocz.github.io/YaQuedo_TetraDev/ actualizado (~2 min)
        │
        └─> Developer crea tag v1.X.Y
             └─> gh release create v1.X.Y --notes "..."
                  └─> Release visible en https://github.com/yagocz/YaQuedo_TetraDev/releases
```

## Validacion del despliegue post-release

Curl tests automatizables que cualquier integrante o el evaluador puede ejecutar:

```bash
# Health check del backend Railway
curl -o /dev/null -w "%{http_code}\n" https://yaquedotetradev-production.up.railway.app/v3/api-docs
# Esperado: 200

# Login devuelve JWT
curl -X POST https://yaquedotetradev-production.up.railway.app/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"ana@yaquedo.pe","password":"password123"}'
# Esperado: {"accessToken":"...","tokenType":"Bearer","expiresInMs":86400000,"user":{...}}

# Frontend Vercel responde
curl -o /dev/null -w "%{http_code}\n" https://ya-quedo.vercel.app/
# Esperado: 200

# Landing Page responde
curl -o /dev/null -w "%{http_code}\n" https://yagocz.github.io/YaQuedo_TetraDev/
# Esperado: 200

# CORS preflight desde Vercel a Railway
curl -X OPTIONS https://yaquedotetradev-production.up.railway.app/api/auth/login \
  -H "Origin: https://ya-quedo.vercel.app" \
  -H "Access-Control-Request-Method: POST" \
  -o /dev/null -w "%{http_code}\n"
# Esperado: 200 + header access-control-allow-origin: https://ya-quedo.vercel.app
```

Los 5 tests fueron ejecutados el 2026-06-13 y todos pasaron.
